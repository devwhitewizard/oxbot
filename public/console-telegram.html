Host Files on Telegram

Securely store your OxBot session files (creds.json) on Telegram for safekeeping and easy sharing.

Why Telegram?

Storing your session ID on a Telegram Channel ensures you never lose access to your bot, even if your VPS is wiped or reinstalled. It acts as a safe cloud backup.

  1. Create a Telegram Channel:
    Open Telegram and create a new Channel. Name it OxBot Backups.
  2. Make Channel Private:
    Go to Channel Settings → Permissions → Channel Type → Change to Private.
  3. Get the ID:
    In the channel URL `t.me/YourName/12345`, the ID is 12345. Copy this ID.
  4. Connect to OxBot:
    Go to the OxBot Dashboard settings and paste the Channel ID to enable auto-backups.
Support Command
Use .backup in your bot group to send the current session file to your Telegram channel automatically.

Need Help?

If your file is not uploading, ensure it is a .json or .txt file and is not larger than 50MB. Bot files are small, so this works perfectly.
